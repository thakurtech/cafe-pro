# Design System Direction

## Principles
- High information density for operations, low cognitive load.
- Touch-friendly POS controls.
- Clear visual hierarchy between live operations and configuration.
- Customer site should feel like the cafe, not enterprise SaaS.
- Owner dashboard should foreground money, exceptions and actions.

## Layout
Merchant:
- persistent navigation
- high-visibility POS entry
- responsive web UI
- keyboard shortcuts on desktop

Customer:
- mobile-first
- fast load
- large tap targets
- minimal required fields
- persistent cart visibility

## Visual rules
- Use semantic colors for state, not decoration.
- Never rely on color alone for kitchen/order status.
- Provide clear success/failure feedback.
- Avoid dense modal chains during peak operations.

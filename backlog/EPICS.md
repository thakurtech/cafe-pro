# Engineering Epics

## E01 Foundation
Repo, CI/CD, environments, auth, tenant model, RBAC, audit, observability.

## E02 Catalog
Categories, products, modifiers, prices, availability, recipes.

## E03 Order Engine
Canonical order model, status machine, order APIs, events.

## E04 POS
Order entry, payments, discounts, receipts, refunds, cash management.

## E05 Offline
Local persistence, sync queue, idempotency, conflict resolution.

## E06 Kitchen
KOT, KDS, station routing, prep state.

## E07 Tables
Floor plan, table state, QR assignment, split/merge.

## E08 Inventory
Ingredients, recipes, consumption, stock adjustments, wastage.

## E09 Merchant Storefront
Website builder, customer storefront, QR, checkout.

## E10 CRM
Customer identity, profiles, segments, history.

## E11 Loyalty
Points rules, ledger, redemption, expiry, reversals.

## E12 Promotions
Coupons, bundles, BOGO, stacking rules, eligibility.

## E13 Games
Game engine, session tracking, reward policies, anti-abuse.

## E14 Referrals
Codes, attribution, eligibility, rewards.

## E15 Campaigns
Audience, schedules, channels, attribution.

## E16 Integrations
Payments, Swiggy, Zomato, messaging, accounting, hardware.

## E17 Reconciliation
Aggregators, payment settlements, discrepancy workflows.

## E18 Analytics
Merchant dashboards, cohorts, revenue opportunities.

## E19 Staff
Roles, shifts, staff analytics, attendance.

## E20 Subscription
Plans, invoices, states, dunning, feature entitlements.

## E21 Platform Admin
Tenant management, support, flags, system health.

## E22 Migration
Imports, mapping, validation, parallel run, cutover.

## E23 Security
Security hardening, abuse, backups, DR, audit reviews.
